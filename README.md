# Hide Durability Bar (NeoForge 1.21.1)

Mod solo-cliente que oculta la barra de durabilidad verde de los ítems.
Inspirado en Custom Durability Bar de leafs4n (MIT, ver LICENSE).

## Compilar
1. Copia `gradlew`, `gradlew.bat` y la carpeta `gradle/` desde cualquier proyecto NeoForge (MDK o tu port de Clash).
2. `./gradlew build`
3. El jar queda en `build/libs/hidedurabilitybar-1.0.0.jar` -> carpeta `mods/`.

Opción en el juego: Mods > Hide Durability Bar > Config. Por defecto está en "ocultar".
